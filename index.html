A cosa serve Piuma?

Piuma è un editor Markdown professionale, leggero e privo di distrazioni. È stato progettato per offrire un'esperienza di scrittura pura e fluida per appunti, documentazione tecnica, articoli e testi scientifici, integrando supporto nativo a formule KaTeX, diagrammi Mermaid, checklist interattive, syntax highlighting e condivisione serverless.

✍️ Sintassi Markdown & Funzionalità Speciali
• Intestazioni: Usa # Titolo 1, ## Titolo 2, ### Titolo 3.
• Formattazione: **grassetto**, *corsivo*, ~~barrato~~, ==evidenziato==.
• Checklist Interattive: Scrivi - [ ] Da fare o - [x] Completato (cliccabili direttamente nell'anteprima).
• Formule KaTeX: Inline $E = mc^2$ oppure a blocco $$\int_{a}^{b} f(x)dx$$.
• Diagrammi Mermaid: Inserisci un blocco di codice con linguaggio mermaid (es. graph TD A-->B).
• Callout GitHub: Usa > [!NOTE], > [!TIP], > [!WARNING], > [!IMPORTANT].
• Immagini e Screenshot: Puoi incollare immagini dagli appunti (Ctrl+V) o trascinarle direttamente nell'editor.
🔗 Condivisione & Modalità Desktop / Web
• Desktop Nativo: Permette di salvare e sovrascrivere direttamente i file .md su disco e apre i collegamenti piuma:// di sistema.
• Web App: Funziona ovunque senza installazione e permette di condividere documenti tramite URL compresso https://...#doc=....
• Importa da Token: Usa il pulsante "Importa da Link / Token" per incollare e caricare istantaneamente qualsiasi documento condiviso.
